# Superseded

This paper has been merged with `papers/paper2-gds/` into a single manuscript:

**`papers/paper2-merged/`** — "Game Deserved Score: Decomposing NFL Team Quality and Testing
the Defensive Dominance Hypothesis"

The merged paper reports the same defensive-dominance hypothesis test on an extended,
256-team-season (2018-2025) sample — including a full out-of-sample season (2025) the original
analysis here did not have access to — and consolidates the four archetype-operationalization
schemes used across the original papers into a single pre-specified primary specification with
the rest reported as robustness checks. This folder is kept for historical reference.
